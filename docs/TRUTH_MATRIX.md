## 원단위 단수처리 (rounding) — 조사 결론 (2026-07-01)

"연상각 = round(원가×상각률)의 round가 맞나, 절사여야 하나?"에 대한 법령·더존·별표4 3방향 조사 결과.

**1. 법령: 원 미만 단수처리 규정 없음.** 법인세법 시행령 제26조(상각범위액) 전문에 절사/반올림/올림 규정 전무. 상각률·잔존가액·비망가(⑦ 취득가 5%와 1천원 중 적은 금액)·월할(⑧⑨)만 규정. → **원단위 처리는 법적 공백 = 실무 재량.**

**2. 별표4는 "절사표"가 아니라 절사·반올림 혼재표.** 공식 별표4(시행규칙) 정액 상각률을 1/n과 대조: **절사 9건 / 반올림 17건 / 동일 33건.**
- 6년 0.166 = 1/6(0.16667) **절사** ✓ / 7년 0.142 절사
- 21년 0.048, 44년 0.023, 59·60년 0.017 = **반올림(올림)**
- → "상각률이 절사니까 상각비도 절사"라는 유추는 **성립 불가**(전제부터 부분참). 상각률 단수(3자리)와 원 단수는 법적으로 독립.

**3. 더존 위하고: 원단위 처리 절사/올림/반올림 선택 설정.** 즉 "더존과 일치"의 정답은 **대상 고객의 더존 설정**. 고객별로 다를 수 있음.

**4. 코드 현황(스멜):** 정액 = `round(cost×rate)` (Python `round`=banker's rounding, 4사5입 아님), 정률 = `int(...)`(절사) → **방법 간 규칙 불일치 + banker's rounding 함정.** 상각률 테이블 자체는 공식 별표4와 **정확히 일치(버그 없음, 6·7·20~23·43~45·59·60 검증)**.

**5. A사 실측 — round vs 절사 실증 결착(2026-07-01):** floor(절사)로 바꿔 A사 3개 대장(99건)을 재대조하니 **FY2025에서 2건이 깨짐**(자산① cost 6,097,749·자산② cost 81,915,104 — 둘 다 원가×0.2 소수부 0.8이라 round=올림/floor=버림이 1원 갈리는 자산). 이 2건은 **더존값이 round와 일치(Δ=0), floor와 불일치(Δ +5·+4, 종료해에서 누적 1원 차 표면화).** FY2022·2024는 //12 마스킹으로 round=floor 동일.
→ **TI 더존 = 반올림(round) 확정.** 코드의 현행 round가 A사엔 정답. (banker's vs 4사5입 구분은 정확 x.500 자산 부재로 미검증.)

**결론/권고 (개정):**
- **A사에는 절사 적용 불가** — 더존이 반올림이라 절사로 바꾸면 상각표와 어긋남(1원 정합 위반). 현행 round 유지가 TI 정답.
- 절사가 "이론적으로 명확"하다는 일반론은 유효하나(한도 보수성·결정성), **실제 대상(TI)의 더존 설정이 반올림이므로 우선한다.** 진짜 기준은 이론이 아니라 고객 더존 설정.
- 잠복 리스크: Python `round`=banker's rounding(5→짝수)라 정확히 `x.500`인 자산에서 4사5입과 1원 갈릴 수 있음(A사 데이터엔 없음). 안전을 원하면 절사가 아니라 **명시적 4사5입**(`math.floor(x+0.5)`)으로 교체가 정석.
- **정률=floor(절사) 실증 확정(2026-07, B사 더존 실측)** — 이전의 "정률 더존 실측이 없어 미검증"은 해소됨. B사 FY2025 정률 진행 2건이 절사/반올림이 실제로 갈리는 데이터였고, 둘 다 **절사만 더존과 일치**:
  - cost 455,000 / 2021-06 취득 → 전기말누계 절사 **399,518** = 더존 ✓ / 4사5입 399,519 ✗
  - cost 1,088,728 / 2022-12 취득 → 전기말누계 절사 **772,916** = 더존 ✓ / 4사5입 772,917 ✗
  → **B사 더존 = 정률 절사**, **TI 더존 = 정액 반올림**(위 5항). 두 고객이 갈리는 게 고객별 설정 차이인지 더존이 방법별로 다르게 처리하는지는 **아직 미구분** — 같은 고객의 정액·정률을 한 대장에서 대조해야 결착된다(B사 정액은 상각완료 1건뿐이라 단수 판별력 없음).
  - 커버리지 한계: 이 실측은 **정률 단순·12월결산**만 덮는다. 정률 CAPEX·부분/전체양도·임의결산월의 절사 규칙은 여전히 손계산 골든이 유일 기준(더존 실측 0건).
- 신규(미확인) 고객용 default가 필요하면 **원단위 처리 파라미터화 + 고객 더존 설정 확인**이 답. 단일 하드코딩 금물.
