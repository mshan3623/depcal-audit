# 시작하기 — 고객 대장 하나 검증하기

대상: 감가상각 검토를 맡은 회계사. 파이썬을 몰라도 아래 명령을 순서대로 치면 됩니다.

먼저 읽어야 할 것: [용도 및 한계](../README.md#-용도-및-한계-고지-감사-실무-사용-전-필독).
**이 도구의 산출물은 감사증거가 아니라 검토 보조자료입니다.**

---

## 1. 설치 (한 번만)

Python 3.9 이상이 필요합니다. 없으면 [python.org](https://www.python.org/downloads/)에서
설치하고, Windows 설치 화면에서 **"Add python.exe to PATH"를 반드시 체크**하십시오.

```bash
git clone <이 저장소 주소> depcal
cd depcal
python -m venv .venv                     # 가상환경 (권장)

# Windows:  .venv\Scripts\activate
# mac/Linux: source .venv/bin/activate

pip install -e ".[test]"
```

설치가 됐는지 확인 — 이 두 줄이 통과해야 다음으로 갑니다.

```bash
depverify --help
pytest -q          # 1,099 passed, 7 skipped 가 정상 (skip은 원저자 로컬 데이터 전용 테스트)
```

`pytest`가 통과하면 **엔진이 손계산 골든값·법령 별표4 상각률표와 일치**한다는 뜻입니다.
계산을 믿기 전에 한 번은 직접 돌려보시길 권합니다.

## 2. 검증 실행

더존(위하고) 고정자산관리대장을 엑셀로 내린 뒤:

```bash
depverify 고정자산관리대장_20241231.xlsx --fy 2024
```

| 옵션 | 언제 쓰나 |
|---|---|
| `--fy 2024` | 검증 대상 회계연도. 파일명이 `..._20241231.xlsx` 형태면 생략 가능 |
| `--fye 3` | 결산월이 12월이 아닐 때 (3월 결산 = `--fye 3`) |
| `--sheet 자산명세` | 대장이 첫 시트가 아닐 때 (시트명 또는 0-기준 번호) |
| `--out 검토조서.xlsx` | 보고서 저장 위치 (기본: `<입력파일>_검증보고서.xlsx`) |
| `--tolerance 10` | 원단위 1~2원 차이를 따로 보고 싶을 때. **기본 0(완전일치)을 권장** |
| `--mapping 매핑.json` | 컬럼명이 더존 표준과 다를 때 (→ 5절) |

종료코드는 `0` = 전건 일치, `1` = 차이 또는 검증불능 존재, `2` = 실행 오류입니다.

## 3. 화면 결과 읽기

```
FY2024 검증 결과: 자산 43건 (구조행 2건 제외)
  허용차 기준: 원단위 완전일치
  일치 41건 / 허용차 0건 / 차이 1건 / 검증불능 1건
  ⚠ 예외 자산 — 보고서의 상단 행 확인:
    [차이] 사무용집기: Δ당기상각 -1,250 / Δ누계 -1,250 / Δ장부 +1,250
    [검증불능] 특허권B: 스코프외-상각방법(생산량비례법)

  엔진 3.x.x (rev abc1234) / 실행 2026-08-24 14:30
  대장 고정자산관리대장_20241231.xlsx  SHA-256 9f2a1c…
```

**판정 4분류의 뜻 — 이 구분이 이 도구의 핵심입니다.**

| 판정 | 뜻 | 해야 할 일 |
|---|---|---|
| **일치** | 취득부터 독립 재계산한 값이 회사 신고값과 **1원까지 같음** | 없음 |
| **허용차** | `--tolerance` 범위 안의 차이 | **일치가 아닙니다.** 개별 확인 |
| **차이** | 재계산값과 어긋남 (Δ 부호·금액 표시) | 원인 규명. 회사가 틀렸을 수도, 대장 입력이 틀렸을 수도 있음 |
| **검증불능** | 재계산 자체를 못 함 | **문제없음이 아닙니다.** 사유별로 개별 확인 |

`검증불능` 사유 코드:

- `스코프외-상각방법(...)` — 정액법·정률법 외 (생산량비례법 등). 이 엔진의 범위 밖
- `스코프외-처분구분(...)` — 양도·미상각분 외의 구분 라벨(폐기·감액 등). 재계산 규칙 미확립
- `스코프외-당기증가조합(...)` — 당기 자본적지출과 처분이 겹친 복합 케이스
- `가드발동: ...` — 입력 자체가 불변식을 위반(예: 기초가액 < 전기말누계). **대장 오류 신호**

`Δ`(델타)는 항상 **회사값 − 재계산값**입니다. `Δ당기상각`이 음수면 회사가 더 적게 상각한 것입니다.

## 4. 보고서 4개 시트

| 시트 | 내용 |
|---|---|
| **자산별** | 자산 한 줄씩 판정·Δ·사유. **차이·검증불능이 맨 위로 정렬**됩니다 |
| **요약** | 판정별 건수와 허용차 기준 |
| **적법성점검** | 재계산이 원리적으로 못 잡는 축 — 업무용승용차 정액 5년 강제(시행령 §50조의2 ③) 위반 후보, 800만원 한도 초과 가능 자산. **판정이 아니라 검토 대상 목록입니다** |
| **고지** | 용도·한계, 그리고 **재현성 정보**(실행일시·엔진버전·소스 리비전·대장 SHA-256) |

'고지' 시트의 SHA-256이 조서의 근거입니다 — 같은 대장·같은 엔진이면 같은 결과가 나옵니다.

## 5. `필수 컬럼 없음`이 떴을 때

```
오류: 대장에 필수 컬럼 없음: ['당기상각비범위액'] — 더존 표준 레이아웃이 아니면 --mapping 지정
```

**이건 고장이 아니라 안전장치입니다.** 컬럼을 못 찾으면 추측하지 않고 멈춥니다.
대장 헤더를 열어 실제 컬럼명을 확인하고 JSON으로 알려주십시오.

```json
{
  "exp_dep": "당기상각액",
  "exp_acc": "당기말감가상각누계액",
  "method": "상각방법"
}
```

```bash
depverify 대장.xlsx --fy 2024 --mapping 매핑.json
```

바꿀 키만 쓰면 되고, 나머지는 더존 표준값이 유지됩니다. 필수 8개 키는 아래와 같습니다.

| 키 | 더존 표준 컬럼명 | 의미 |
|---|---|---|
| `acq_date` | 취득일자 | 취득 연월 |
| `beginning` | 기초가액 | 유형=취득원가 / 무형=기초 장부가 |
| `prev_acc` | 전기말상각누계액 | 전기말 누계 |
| `life` | 연수 | 내용연수 |
| `method` | 상감법 | 정액법 / 정률법 |
| `exp_dep` | 당기상각비범위액 | 회사 신고 당기상각 |
| `exp_acc` | 당기말상각누계액 | 회사 신고 기말누계 |
| `exp_bk` | 당기말장부가액 | 회사 신고 기말장부가 |

선택 키(있으면 정확도가 올라감): `account`(계정과목), `asset_name`, `asset_code`,
`capex`(신규취득및증가), `category`(구분), `disposal_date`(양도/폐기일),
`prev_book`(전기말장부가액 — **유형/무형 판별의 1순위 근거**).

## 6. 첫 대장에서는 반드시 표본 대조를 하십시오

이 리더는 지금까지 **소수 기업의 더존 대장**으로만 검증됐습니다. 레이아웃이 다르면
`필수 컬럼 없음`으로 멈추는 게 정상 동작이지만, **드물게 조용히 잘못 읽을 수 있습니다**
(실제로 과거에 거짓 불일치 1건·거짓 일치 1건이 발생한 기록이 있습니다).

새 고객 대장의 첫 회에는:

1. `일치` 판정 중 **3~5건을 골라 손계산으로 직접 대조**하십시오.
2. `차이`가 났다면 **대장 원본 행을 눈으로 확인**하십시오 — 도구가 컬럼을 잘못 읽었을
   가능성이 회사가 틀렸을 가능성보다 먼저입니다.
3. 무형자산이 `유형`으로 잡혔는지 보십시오. 취득원가가 순장부가로 축소되면 그 신호입니다.

**결과가 이상하면 그 대장을 원저자에게 보내주십시오.** 반례가 이 도구에 가장 값진 입력입니다.
이때 보고서 **'고지' 시트의 `엔진 버전`·`소스 리비전`** 두 줄을 함께 보내주십시오 — 어느
판본에서 난 문제인지 그 두 값으로만 특정됩니다. 리비전이 `미상(설치본)`으로 찍혔다면
`.git` 없이 받은 사본이라는 뜻이니, 그 사실도 같이 알려주십시오.

## 7. 고객 데이터 취급

- **대장 파일을 이 저장소 안에 두고 커밋하지 마십시오.** `.gitignore`가 `sample_data/*.xlsx`를
  막아두었지만, 다른 경로에 두면 막히지 않습니다. 대장은 저장소 **밖**에 두고 경로로 넘기십시오.
- 보고서(`*_검증보고서.xlsx`)에도 자산명이 들어갑니다 — 조서와 같은 등급으로 취급하십시오.
- 웹 UI(`dep_cal_web.py`)는 기본이 루프백(`127.0.0.1`) 바인딩입니다. 사내망에 열지 마십시오.

## 8. 범위를 넘어가는 것

이 도구는 **법인세법 [별표 4] 상각표 재현 + 대장 재계산 대조**만 합니다.
상각부인액·시인부족액 등 세무조정, 감가상각의제, 중고자산 수정내용연수, 상각방법 변경 신고,
K-IFRS 회계상각 이원화, 업무용승용차 특례의 세무조정 부분, 사업연도 12개월 미만 안분은
**범위 밖**입니다. 전체 목록은 [README의 범위 절](../README.md#️-범위-반드시-읽어주세요)에 있습니다.

검증 등급을 계산 경로별로 보고 싶으면 [TRUTH_MATRIX.md](TRUTH_MATRIX.md)를 보십시오 —
어느 경로가 손계산 골든으로 검증됐고 어느 경로가 자기참조뿐인지 표로 정리돼 있습니다.
